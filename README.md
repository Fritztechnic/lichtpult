# Lichtpult

Open-Source-Lichtsteuerung für Bühnentechnik, nativ für Linux, geschrieben in Rust (egui).

Status: frühes MVP – 512 DMX-Fader, Blackout, Art-Net-Ausgabe mit 44 Hz (Broadcast, Universum 0).

```
cargo run --release
```

## Roadmap
1. Fixture-Patch (OFL/GDTF-Import), Programmer
2. Cue-Liste mit Fades, Gruppen, Paletten, Effekte
3. sACN, USB-DMX, MIDI/OSC, 2D-/3D-Visualizer
